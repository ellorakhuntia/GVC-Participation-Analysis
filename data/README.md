# Data

This folder is intended to store the datasets required to reproduce the analysis.

## Data Source

- World Bank Enterprise Survey (WBES), India
- Survey years: 2014 and 2022

## Note

The original WBES dataset is **not included** in this repository due to World Bank data licensing restrictions.

Users can obtain the dataset from the official World Bank Enterprise Surveys website and place the required files in this folder before running the analysis scripts.

Future versions of this repository may also include documentation describing the data preparation process and variable construction.
