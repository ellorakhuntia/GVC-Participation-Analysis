# Output

This folder contains the outputs generated from the empirical analysis.

## Contents

The folder includes:

- Descriptive statistics tables
- Balance diagnostics
- Propensity Score Matching (PSM) results
- Average Treatment Effect on the Treated (ATT) estimates
- Regression output tables
- Exported log files

## Note

All files in this folder are generated automatically by the Stata scripts contained in the `scripts/` directory. Users can reproduce these outputs by running the analysis workflow.
